### 09/30 FlexiCache 官方 source 的本機可行性試跑

**問題與原先假設**：使用者要求實際試跑 FlexiCache，確認官方 H100/vLLM fork 能否在 RTX 5060 Ti 16GB 使用。原假設為模型 profile 與資源配置可適配，CUDA/kernel 相容性尚需實測。

**證據與處理**：官方 GitHub shallow checkout `ab0f495b10fc6509c1637af35779b29121fb7d3f`，獨立 `.venv` overlay 現有 PyTorch 2.7.0+cu128；未修改 HeadInfer 環境。官方 xgrammar 0.1.16 無法下載，試跑改用 0.1.17。CMake PATH、NVTX3 header discovery 與 CUDA include layout 的失敗 log 均保留。

**已量測結果**：官方 `h2d_copy_blocks.cu`、`kv_d2h_tx_gpu_mapped.cu` 在 sm_120 編譯，FP16 與 BF16 各以 3 個非連續 blocks 做 H2D/D2H，每方向 payload 24,576 bytes；兩種 dtype 均逐 element exact。這是小型獨立 kernel correctness probe，無 formal TPOT。

**補充 kernel gate**：另兩個 `block_table_h2d_dirty`、`topk_swap_map` CUDA 模組已編譯及載入。官方 odd-GQA page scorer 以 24 query heads / 8 KV heads / head_dim 128 / 128 pages 的 synthetic metadata 測試，首步及第 16 步 reference allclose 通過（最大 BF16 score 差 0），第 2 步 stable heads 維持 skipped。這是獨立 kernel gate，未驗證完整模型 logits。

**目前結論與限制**：這兩個 UVA/pinned-memory transfer kernels 在本 GPU 可用；完整 source build 與 editable install 已通過。256 input + 32 output 的 FlexiCache 未裁剪生成 IDs 全部匹配 dense；2048 input + 64 output 的稀疏生成、官方 stability analysis 與 56 unstable / rerank=16 hybrid pilot 均已完成。尚未有正式品質或 TPOT gate。CPU pool 2K pilot 設為 1 GiB、avg tokens 4096；32K 成功設定為 4 GiB、avg tokens 32768；3B 僅登錄空 profile 供零 unstable 的 diagnostic collection，已補單一合成 prompt 的 pilot 分類（224 heads 中 56 unstable）；不是跨任務正式 profile。

**Artifacts**：`results/flexicache_port_20260930/`；`scripts/{run_flexicache_smoke,probe_flexicache_transfer,probe_flexicache_selector}.py`、`scripts/run_flexicache_local.sh`；獨立報告 `reports/flexicache_local_feasibility_2026-09-30.md`；外部 checkout `../../external/flexicache-20260930/`。

**後續相容性處理**：Triton 3.3 compiler 不支援 sm_120 matmul，overlay 改用 3.4.0，留下 torch pin mismatch。Prefill 原 3-stage kernel 需 163840-byte shared memory、硬體上限 101376；僅 sm_120 改為 1 stage 後生成通過。跳過 Hopper FA3/FlashMLA build，FA2 與主要 extensions 已完成。32K 初試 allocator avg=4096 導致重複 preemption，停止後改 avg=32768、CPU pool=4 GiB 重試，32768 input + 64 output 成功並完成 CUDA synchronize。實際 transfer audit：H2D 3 calls / 16053 head-blocks，D2H 11 calls / 344568 head-blocks（16 tokens/head-block）；不是 bandwidth 或 latency。

**下一決策**：32K feasibility 已通過。正式比較前補跨任務 profile/quality 與 matched VRAM / prompt / output / TPOT protocol；不可將 synthetic pilot 的成功生成當作準確度或效能相當。
